# Facer Studio

Нативная панель управления RGB-клавиатурой Acer Predator/Nitro для установленного драйвера Facer.

Возможности:

- все шесть режимов Facer: статичный, дыхание, неон, волна, перелив и импульс;
- программные режимы **«Аврора»**, **«Комета»** и **«Палитра»**;
- HSV-круг, HEX, точный RGB и независимые цвета четырёх зон;
- яркость, скорость, направление и выбор активных зон;
- плавный живой предпросмотр до и после применения;
- встроенные и пользовательские профили;
- мгновенное переключение русского/английского интерфейса кнопкой **Eng/Рус**;
- системный трей, single-instance и фоновый автозапуск;
- автоматическое восстановление последней подсветки после входа в систему;
- понятная диагностика отсутствующего устройства или прав доступа.

## Цвета четырёх зон

В режимах **«Статичный»**, **«Аврора»**, **«Комета»** и
**«Палитра»** каждой физической зоне можно задать свой базовый цвет.
Выберите **«Зона 1»–«Зона 4»**, затем измените её цвет через RGB-круг, HEX или
точные значения RGB. Повторите для остальных зон и нажмите **«Применить»**.
Кнопка **«Цвет → всем»** копирует активный цвет сразу во все четыре зоны.

Поклавишная адресация этой клавиатурой и интерфейсом Facer не поддерживается:
драйвер принимает только маску одной из четырёх физических зон и один RGB-цвет.

Для **«Дыхания»**, **«Перелива»** и **«Импульса»** тоже можно выбрать разные цвета:
в этом случае Facer Studio автоматически воспроизводит эффект программно с частотой
5 FPS. Если цвета всех зон одинаковы, используется родной режим прошивки клавиатуры.
**«Неон»** и **«Волна»** сами генерируют цвета и не поддерживают ручную настройку зон.

## Программные эффекты

- **Аврора** — переливающийся градиент базовых цветов плавно движется по зонам.
- **Комета** — яркий импульс ходит между краями, окрашивая хвост по базовому цвету зоны.
- **Палитра** — зоны плавно переходят между четырьмя выбранными базовыми цветами.

Выберите эффект, настройте цвет, яркость и скорость, затем нажмите
**«Запустить»**. Окно можно закрыть: Facer Studio останется в трее, а эффект
продолжит работать. Все программные эффекты обновляют подсветку примерно пять раз
в секунду, чтобы не перегружать WMI-драйвер.

Программные эффекты не могут отменить аппаратный таймаут EC/BIOS и не разбудят
уже погасшую клавиатуру.

## Запуск

```bash
./facer-studio
```

Демонстрационный режим без обращения к устройствам:

```bash
./facer-studio --demo
```

## Установка в меню KDE

```bash
./install-user.sh
```

После установки приложение появится в меню как **Facer Studio**. Root не требуется.
Также создаётся пользовательский XDG-автозапуск: при входе в систему приложение
стартует скрытым в трее и восстанавливает последний выбранный режим. Если драйвер или
udev ещё не готовы, Facer Studio дожидается устройства и повторяет попытку.
Повторный запуск не создаёт второй процесс, а открывает
уже работающий экземпляр.

## Требования

- Python 3.8+;
- PyQt6;
- загруженный модуль Facer;
- право записи в `/dev/acer-gkbbl-0` и `/dev/acer-gkbbl-static-0`.

Настройки сохраняются в `~/.config/facer-studio/settings.json`.
